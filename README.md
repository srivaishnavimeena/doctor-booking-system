# Doctor Availability and Booking System

Desktop app built with Python, Tkinter and SQLite.

## Features

- Login with admin and receptionist roles
- Doctor, patient and availability management
- Booking with automatic free-slot calculation (no double-booking)
- Cancel and reschedule appointments

## How to run

1. Install Python 3
2. Run `python main.py`
3. Log in with admin / admin123 (or reception / recep123)

The database (hospital.db) is created automatically on first run.
